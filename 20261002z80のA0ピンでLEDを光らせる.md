
# やりたいこと

z80を使ってLEDを光らせます。
z80にはP1ピンの様に直接ピンを使って外部機器を操作することが出来ません。
OUT命令を使うようですが、チップを追加してポート番号を変換する必要があるようです。
そこで今回は手始めにアドレスバスであるA0ピンを使います。

# 方法

以下のようにJP命令を2つ使います。
アドレスがするとアドレスバスが`00000000`と`00000011`の間を行き来します。
A0が交互に1と0に切り換わる為、ここにLEDを繋げると点滅すると仮説を立てました。


```bash
z80asm -o a0led.bin a0led.asm
```

```a0led.asm
jp 0x0003
jp 0x0000
```
